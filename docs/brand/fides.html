    How it works

    From a PDF in the Sbírka listin to a credit view in one run.

    One deterministic pipeline, run locally with python -m src.pipeline. Only the final assessment calls a language model.

    1. Locate the statements

      Finds the balance sheet and income statement pages inside a long annual report.

    2. Read every page

      Uses the PDF text layer where it exists and Tesseract OCR with Czech language data where the page is a scan. Keeps the position of every word.

    3. Parse to a schema

      Matches line codes and Czech labels to a fixed data model, detects columns, units (Kč, tis. Kč) and periods.

    4. Validate and re-read

      Checks accounting identities. When a total does not add up, re-reads the suspicious cells with tuned OCR and flags what still fails for a human.

    5. Analyse

      Computes liquidity, leverage and profitability ratios, the IN05 index and Altman Z-score, with year-over-year trends and industry traffic lights.

    6. Write the assessment

      Generates a short structured report, then checks every number in it against the extracted data and marks anything it cannot confirm.

    Why you can trust it

    Nothing is a black box. Every value can be checked in one click.

    Bounding box for every value

    Each number keeps its page, line code and position. Analysts compare it with the original instead of trusting a table.

    Statements must balance

    Assets must equal liabilities and every subtotal must equal its parts. A failed check is shown, never hidden.

    Humans review the doubtful

    Low OCR confidence and failed checks are flagged and editable. Fides supports the analyst's decision; it does not replace it.

    Data stays in-house

    Extraction and analysis run locally with open-source OCR. The language model sees only the extracted figures, never the documents.
