# Fides brand (CIPW-21)

**Fides — Financial Insight & Data Extraction System.** *Fides* is Latin for trust. Tagline: **Every number, traced to its page.**

- One-page intro: [`fides.html`](fides.html) (live: https://claude.ai/artifact/Jbh7zHTwP2JT3zAX3jwGVx)
- Mobbin references: [`inspiration.md`](inspiration.md)

## Logo

The mark is a red square with an **F built from two statement rows**. The lower row ends in a **yellow bounding box** around the value, the same box the app draws around every extracted number (CIPW-18). Colours follow the Cofidis red/yellow requirement in CIPW-18.

| File | Use |
| --- | --- |
| `logo/fides-logo.svg` | Main lockup (mark + wordmark) on light backgrounds |
| `logo/fides-logo-white.svg` | Lockup on dark backgrounds and photos |
| `logo/fides-mark.svg` | Mark alone: app icon, favicon, Streamlit `page_icon`, slide corner |
| `logo/fides-mark-yellow.svg` | Alternative mark on red or neutral slides |
| `logo/fides-mark-mono.svg` | Single-colour print |
| `logo/fides-wordmark.svg` | Wordmark alone |
| `logo/*.png` | Raster exports (512, 192, 32 px mark; 1200 px lockup) |

Colours: red `#D52B1E`, yellow `#FFC72C`, ink `#1E1A18`. Wordmark: Newsreader SemiBold (SIL OFL), outlined. UI type: IBM Plex Sans / Plex Mono for numbers.

Rules: minimum mark size 16 px; clear space = F stem width; do not recolour, rotate or put the mark on busy images. Do not lock the Fides logo together with the Cofidis logo; show "Built for Cofidis" separately and only with their approval.
